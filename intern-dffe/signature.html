How to Add This to Microsoft Outlook

1
Copy Signature
Click the green "Copy Signature" button at the top of this page.
2
Open Outlook Settings
Outlook Desktop: Go to File → Options → Mail → Signatures.
Outlook Web / 365: Click Settings ⚙️ → Mail → Compose and reply.
3
Paste & Save
Create a new signature, click inside the edit box, and press Ctrl + V (Paste), then click Save.
